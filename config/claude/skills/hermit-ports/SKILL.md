# 五、服务端口

容器内 Web 服务固定暴露端口：8082

你的应用应监听 8082 端口。宿主机通过 19081-19999 之间的端口访问。

SSH 服务监听容器内端口 22，通过 host_port - 10000 的端口映射访问。

⚠️ **端口范围规范：**
  - 19080：Hermit Control 控制面板
  - 19081：Hermit Tools Hub（由 19081-hub 容器提供，对接文档首页 + /api/tools 接口）
  - 19000-19079：工具类容器端口
  - 19081-19999：普通容器端口
  - 工具类与普通容器都在 Control 面板以卡片展示，卡片可选择是否注册到 19081 Hub
