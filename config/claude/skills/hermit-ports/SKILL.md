# 五、服务端口

容器内 Web 服务固定暴露端口：8082

你的应用应监听 8082 端口。宿主机通过 18081-18999 之间的端口访问。

SSH 服务监听容器内端口 22，通过 host_port - 10000 的端口映射访问。

⚠️ **端口范围规范：**
  - 18000-18079：工具类端口段（obs 图床=18000、email 邮件=18001；fork 为工具的新容器也从这里分配）
  - 18080：Hermit Control 控制面板
  - 18081：Hermit Tools Hub（由 18081-hub 容器提供，对接文档首页 + /api/tools 接口）
  - 18081-18999：普通容器卡片端口
  - 工具类与普通容器都在 Control 面板以卡片展示，卡片可选择是否注册到 18081 Hub
